# Container image (melange + apko)

Distroless Wolfi runtime for `gitlab-compliance`.

## Layout

- `melange.yaml` — builds one APK that vendors a pip-less virtualenv from
  `poetry.lock`
- `apko.yaml` — assembles the final nonroot image (`python-3.14` + that APK)
- `apko.lock.json` — pinned Wolfi package set (regenerated by the build script)

## Build

```bash
LOAD_IMAGE=1 bash scripts/build-image.sh
docker run --rm maturitybuilder/gitlab-compliance:local --help
```

## Pins to update

Dependabot's docker ecosystem only bumps `Dockerfile` `FROM` lines. This image
build no longer uses a Dockerfile. Refresh these pins instead:

1. `MELANGE_IMAGE` and `APKO_IMAGE` digests in `scripts/build-image.sh`
2. `image/apko.lock.json` (run `bash scripts/build-image.sh` after index changes)

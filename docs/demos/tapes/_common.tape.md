# Shared VHS settings (copy into each tape; VHS has no include).

Recommended defaults:

```
Set Shell "bash"
Set FontSize 14
Set Width 1280
Set Height 720
Set TypingSpeed 40ms
Set Theme "Catppuccin Mocha"
Set PlaybackSpeed 0.5
```

Run tapes from the repository root via `bash scripts/record-demos.sh`.

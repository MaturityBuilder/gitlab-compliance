# Installation

Install `gitlab-compliance` with Python for local development, or run the
published container image in CI.

## Methods

| Method                         | Best for |
| ------------------------------ | -------- |
| [Installing via pip](pip.md)   | Local development, virtual environments, and Python-based CI jobs |
| [Docker image](docker.md)      | Containerized CI jobs and pinned image deployments |

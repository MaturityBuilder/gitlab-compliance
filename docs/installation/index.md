# Installation

Install `gitlab-compliance` with Python for local development and CI jobs, or
run the published container image when your pipeline standardizes on Docker.

## Methods

| Method                           | Best for                                        |
| -------------------------------- | ----------------------------------------------- |
| [Installing via pip](pip.md)     | Local development, Poetry projects, and CI jobs |
| [Running with Docker](docker.md) | Containerized CI jobs and isolated smoke tests  |
